# Homepage design plan

- User and task: A curious builder, journalist, or civic technologist should understand why Marc builds in public, see how the work connects, and reach a relevant live site or repository.
- Surface mode: Marketing.
- Style dials: Variance high; density relaxed; motion expressive but nonessential; type branded; imagery role evidence-and-explanation.
- Structural fingerprint: Manifesto to public proving grounds to open-source ledger to building principles.
- Harness / requested model / served model / tier / capabilities: Codex / GPT-5 / GPT-5 / frontier / browser and visual input. DES profile `des-marketing-frontier-aabeefb9ab26`.
- Lowest unresolved layer: The existing site has no product argument, project map, or useful action path.
- Existing system to preserve: The current public project descriptions and destinations from the actively maintained GitHub profile README.
- Named system pattern or documented gap: Purpose-built proof-led portfolio argument; a marketing-specific local composition using DES mode contracts and semantic tokens.
- Existing pattern readiness and missing behavior: The DES marketing mode and audit gate are documented and executable; this site needs its own identity and production content.
- Reference and mechanism borrowed: Eno excerpt-first retrieval over Central; the mechanism is personal friction becoming a used tool, then reusable public infrastructure.
- Anti-reference / behavior to avoid: Centered slogan, logo strip, three feature cards, testimonial wall, generic AI claims, invented adoption metrics, and decorative browser chrome.
- Flow and states: Arrive at the argument; choose public experiments or open-source stack; inspect detailed project rows; follow a working destination. Static HTML leaves no loading or empty state. Failed third-party destinations remain normal browser-recoverable links.
- Hierarchy and density: Large editorial opening; compact explanatory system map; spacious public-work rows; denser open-source ledger; concise manifesto close.
- Surface expression: Warm paper, ink, signal orange, editorial serif, strong rules, numbered public experiments, and an animated systems loop that becomes static under reduced motion.
- Coherent slice to change: Replace the generated Jekyll placeholder homepage with a complete static index, stylesheet, favicon, and repository documentation.
- Proof required: DES baseline and variant audits at 1440, 768, and 390; keyboard task walk; link verification; visual inspection at full and thumbnail size.
- Promotion authority: Candidate until independent seeing or explicit human acceptance.
