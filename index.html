I build small open-source tools for research, decision-making, journalism, and creative work with AI. This page records what ships from those projects: what grew, what changed, what got fixed. Each entry links to the code, the release, and the docs where they exist.

Find me on GitHub, X, and LinkedIn. The current homes of the work are Lyra Forge and Lyra-TK.

Research & evidence

  • flip (docs) — Format and tooling for agent-driven research notebooks.
  • flip-documents — Original document capture and conversion for Flip notebooks.
  • flip-github — Complete GitHub issue, PR, and Discussion capture for Flip notebooks.
  • flip-papers — Exact DOI and arXiv evidence capture for Flip notebooks.
  • flip-publication — Editorial handoff workflow and templates for Flip notebooks.
  • flip-reddit — Reddit thread evidence with original Atom custody and a Flip adapter.
  • flip-youtube — Timestamped caption and ASR evidence for Flip notebooks.
  • flip-examples — Real, browsable flip notebooks.
  • flip-research — A small default for flip's research role: web search, a plain page fetcher, and an optional model — public pieces only.
  • ergo — Dataset documentation with structured, code-linked known-issue registries.
  • ergo-directory — An index of published ergo data pages, clustered by subject.
  • pallet — Local-first dataset acquisition with custody: capture the bytes, shape a documented table, publish immutable releases pinned by hash.

Knowledge & commitments

  • eno (docs) — Structural intelligence and gardening for your Obsidian vault — CLI, MCP, and HTTP.
  • daymark — Tasks, plans, recurrence, and durable reminder state for people and their agents.

AI infrastructure & operations

  • somm (docs) — LLM call management and optimization: telemetry, routing, model memory.
  • gipper (docs) — Run GPU jobs across cloud markets: estimates, collection, verified teardown, a local ledger.
  • chip — A contract for portable, versioned operational components.
  • chipsocket — The socket runner for chip, and its minimal second host.
  • milton — Graded, typed findings over agent exhaust — sessions, receipts, ledgers, git.

Agent tooling

  • spindle (docs) — Choose, hand over, and track the skills coding agents use.
  • cub — A CLI for Ralph + Beads-style development with harnesses like Claude Code and Codex.
  • yoinker — Understand how it works; yoink what transfers.

Publishing & visualization

Shared surfaces for people and agents

November 2026

Nov 26 — toucan v0.23.0. A tab left open across an upgrade used to keep running the old page, so new helpers failed in it with errors that didn't say why. Now each tab learns the server's build when it connects. After an upgrade it shows toucan was updated · Reload, and an agent's failed run in that tab names the cause. toucan reload --all reloads every open tab at once, headless pages included, and nothing is lost because the canvas is already saved. Code · Docs

Nov 26 — toucan v0.22.1. The canvas in the chat. toucan mcp is now an MCP App: in a host that shows them, such as Claude, an agent that opens or draws a canvas puts a live view of it in the conversation. When you rename a box in toucan, the picture in the chat updates within a couple of seconds, and the agent hears what you changed with its next call. The view has no network access of its own. It gets pictures through the host, so it works with the local stdio server and never sees the server's token. Also in this release: renditions, which are named, published pictures of part of a canvas that a document can include, and the Letterpress and Admiralty palettes. (0.22.0 was tagged but not published.) Code · Docs

Nov 24 — flip v0.27.0. Passage pins on any held source. flip source passage pin records the exact words a claim rests on — a quote or a line range, with the SHA-256 of the pinned words and of the copy they were read from, and which copy that was: the raw bytes or the extraction that produced them. A quote that is not in the held copy names its nearest match; unpin is refused while a claim cites the pin; a label whose words moved in a re-extraction can be re-anchored. Claims cite pins as --source A3§label, and doctor's excerpt checks now cover every source with held text. A recorded --basis on claim verification names the written rule a record was made under. Code · Docs

Nov 23 — yoinker v0.3.0. Decision records. An assessment worth finding again is kept with the project it concerns (docs/yoinker/ by default) or in a per-user store, and stays out of public repositories unless the user asks. A dependency-free helper finds an earlier record, opens a new one with a stable name, and pins a forge repository to its default-branch commit without cloning it. An append-only outcome log keeps a borrow that landed, a test result, an expiry or a reversal attached to the decision. The change retired a private service that had been the only place assessments lived; its 63 assessments moved into the projects they concern. Code · Site

Nov 23 — vizier v0.4.0. Look first, then show. A request to see data is now a good request: vizier ranks the ways to show it, draws the best ones, states the trade-offs, and when a sentence, a stat tile or a table would serve the reader better, says so and provides it beside any chart it can draw — it no longer answers with a refusal. vizier explore answers "what is in this table?" before there is a claim: a contact sheet of small static views with each field's oddities (round-number spikes, long tails, dominant values, likely missing-value codes) and missingness by field and group. Derisive wording softened where it was tone rather than substance. Code · Docs

Nov 23 — toucan v0.21.0. One Export menu for every way out of a canvas: a picture as SVG or PNG, the animated build, a file another tool reads, or what the diagram says in words. An exported SVG carries its title and that description inside it, and toucan describe prints the words, so an agent can check a diagram against what was asked without a picture. toucan export OUT writes any of them by the file's ending. Also fixes the first command on a canvas just made from a template seeing it empty. The description follows open-diagram by Luke Deasy. Code · Docs

Nov 23 — toucan v0.20.0. Toucan draws systems maps: panels of tiles in columns, so twenty named parts fit where a flow chart held six. Any part can carry a state (live, being built, in trial, planned, retiring), shown by colour and by word, and the key lists only the states the picture uses. A long arrow travels round the outside instead of through a panel, and the diagram check now says what to run or change for each thing it finds. The form follows open-diagram by Luke Deasy. Code · Gallery

Nov 23 — artoo v0.12.0. A diagram has to say what it shows. artoo verify warns about a Mermaid diagram with no accDescr:, the description a screen reader says and an agent can check against the request. Nov 23 — yoinker v0.2.0. Yoinker now covers the request that authorizes implementation: it assesses first, adopts only what the assessment supports, repeats the comparison after the change, and credits what it took. Assessing an artifact now means running its example inputs through your own system and comparing the results, since a local check that passes a worse result is the finding. The held-out comparison of the skill has still not been run. Code · Site

Nov 23 — milton v0.2.0 and v0.2.1. Code
