01 Why build

The work begins at the friction.

A problem in reporting, research, or civic life becomes a small tool. The tool gets used hard. If the useful part generalizes, it becomes infrastructure other people can inspect, adapt, and improve.

That path—from personal need to public component—is more interesting to me than building software from a market category backward. It keeps the abstractions honest and the feedback close to the work.

The projects here are separate on purpose. A reporter’s notebook should not become a model router; a public school site should not become an agent console. They share contracts and lessons without collapsing into one giant platform.

03 Open-source stack

Small tools, connected by the work.

These projects are designed to stand alone. Together, they form a loop for seeing what agents did, giving them better context, preserving evidence, and turning the result into something people can use.

I

Observe model calls and agent work closely enough to improve the system instead of guessing.

somm

Self-hosted LLM telemetry, routing, and model memory. Record calls locally, route across providers, and evaluate workload-to-model fit.

milton

Agent-work intelligence. Turn transcripts, runner receipts, gateway ledgers, and Git activity into evidence-graded findings about cost, outcomes, and recurring failure.

Give humans and agents durable memory without confusing a fluent answer for evidence.

04 Building principles

Fast output makes judgment more important, not less.

Most of the code in these repositories is generated with AI. Much of it is alpha. Publishing the work is part of the discipline: contracts, tests, provenance, limitations, and failure modes become inspectable.

01

Evidence before confidence

Receipts, sources, and caveats should survive the model call that used them.

02

Local first when it matters

Private notes and operational traces should not need to leave the systems that own them.

03

Human authority stays visible

Agents can act, report, and create—but consequential judgment needs a named owner.

04

Open the reusable layer

Share the component that travels; preserve the local context that makes a product useful.

The repos are the invitation

Use a tool. Fork an idea. Tell me where the abstraction breaks.

The work is public because useful systems get better when people can inspect the seams—not because every experiment is finished.
